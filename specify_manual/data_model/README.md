# Data Model Documents

This directory contains data model documentation derived from the code in `src/domains/models`.
Each document briefly describes the purpose, structure, and relationships of a model.

## Covered Models
- `layer.md`: annotation layer definition
- `meta.md`: meta-layer annotations
- `abstract_annotation.md`: abstract-layer annotations
- `spec_detail.md`: spec-detail-layer annotations
- `implementation.md`: implementation-layer annotations
- `annotation.md`: aggregation of document/code annotations and units
- `trace.md`: traceability definitions between spec and implementation
